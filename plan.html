Step 2 Label collision avoidance ▼
index.html

Greedy label placement sorted by node importance. No overlapping text.

  • Sort nodes by connection count (most-connected labeled first)
  • For each node, try 4 positions: above, below, right, left
  • Track placed bounding rects using ctx.measureText()
  • Skip label if all 4 positions collide — the node dot is still visible
  • Hovered & searched nodes always get a label (forced override)

Step 4 LLM generator — multi-backend ▼
generate.py

Python script that calls an LLM to expand the knowledge graph. Supports 5 backends, defaults to OpenAI.

Generation loop:

  • Load existing knowledge.json (or start empty)
  • Pick expansion targets: underrepresented domains, few-connection nodes
  • Prompt LLM with existing concept IDs + domain focus → get new concepts + links as JSON
  • Merge & deduplicate, checkpoint after each batch
  • Runs until interrupted (Ctrl+C saves) or --rounds limit
python generate.py --input knowledge.json --output knowledge.json python generate.py --backend claude --rounds 5 --input knowledge.json --output knowledge.json python generate.py --backend gemini --seed-domain "psychology" --output knowledge.json
